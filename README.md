# 📈 StockPilot 학습 로드맵

## 🎯 목표

- **이직 목표:** 금융권 IT 백엔드 개발자 (2025년 12월)
- **메인 프로젝트:** [StockPilot](https://github.com/gayulz/stockpilot) — 개인 주식 포트폴리오 관리 시스템
